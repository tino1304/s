---
description: Initialize S plugin for current project
---

1. Check `CLAUDE.md` exists. If missing → tell user to run `/init` first, STOP.
2. Read `CLAUDE.md` + project config files (`package.json`, `pubspec.yaml`, `go.mod`, `Cargo.toml`, `pyproject.toml`, `tsconfig.json`, `vite.config.*`, `next.config.*`, `tailwind.config.*`) to detect tech stack.
3. Read `${CLAUDE_PLUGIN_ROOT}/skills/skill-index.json`. Match project tech against skill keywords.
4. Create `.claude/s/skills.md`:

```markdown
# Project Skills

## Matched
- **[name]** → `[skill path]` (matched: [keywords])

## Stack
Language | Framework | Styling | State | Build | Test | Other

## Note for Agents
Before starting work, also read `.claude/s/mapper.json` for reusable code locations.
```

5. Scan project for reusable functions in common paths (utils, helpers, shared, lib, common, hooks, composables, pkg, internal/common, etc.) AND functions that are imported/used in many places across the codebase. Create `.claude/s/mapper.json` indexing each function with its name, file location, description, and keywords so agents can quickly find and reuse them. If none found, create template for user to configure:

```json
{
  "reusable": [
    { "name": "functionName", "path": "src/utils/file.ts:42", "description": "What it does", "keywords": ["keyword1", "keyword2"] }
  ]
}
```

6. Create `.claude/s/README.md`:

```markdown
# S Plugin Config

Auto-generated by `/s:init`. Edit these files to customize.

- **skills.md** — Matched skills. Agent loads relevant guidelines from here.
- **mapper.json** — Reusable functions index. Maps function names, locations, descriptions, and keywords so agents can find and reuse existing code.
- **backlog.md** — TODO items found in codebase. Quick view of pending work.

Re-run `/s:init` to refresh all files.
```

7. Scan all source files for TODO comments (`// TODO`, `# TODO`, `/* TODO`, `<!-- TODO`, `-- TODO`). Collect each with file path, line number, and the TODO text. Create `.claude/s/backlog.md`:

```markdown
# Backlog

TODOs found in codebase. Re-run `/s:init` to refresh.

| # | File | Line | TODO |
|---|------|------|------|
| 1 | `src/auth.ts` | 42 | TODO: add token refresh |
```

If no TODOs found, create the file with an empty table and a note: "No TODOs found."

8. Show summary. Do NOT modify CLAUDE.md.
