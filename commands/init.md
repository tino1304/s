---
description: Initialize S plugin for current project
---

1. If `CLAUDE.md` does not exist, run `/init` to create it.

2. Create `.claude/s/` directory and template files:

   - **`.claude/s/skills/mapper.md`:**
   ```markdown
   # Skill Map

   ## Stack
   | Language | Framework | Styling | State | Build | Test | Other |
   |----------|-----------|---------|-------|-------|------|-------|
   | — | — | — | — | — | — | — |

   ## Skills
   | Skill | File | Keywords | Description |
   |-------|------|----------|-------------|

   Run `/s:scan` to detect your tech stack and generate project-specific skills.

   ## Note for Agents
   Read the skill file(s) relevant to your task from `.claude/s/skills/` before writing code.
   Also read `.claude/s/mapper.json` for reusable code locations.
   ```

   - **`.claude/s/mapper.json`:**
   ```json
   {
     "reusable": []
   }
   ```

   - **`.claude/s/backlog.md`:**
   ```markdown
   # Backlog

   | # | File | Line | TODO |
   |---|------|------|------|

   No TODOs found. Run `/s:scan` to detect TODOs in your codebase.
   ```

   - **`.claude/s/README.md`:**
   ```markdown
   # S Plugin Config

   Auto-generated by `/s:init`. Edit these files to customize.

   - **skills/** — Project-specific skill guidelines. Each `.md` file covers one development concern.
   - **skills/mapper.md** — Index of all skills with keywords for matching.
   - **docs/** — Project overview and structure documentation.
   - **mapper.json** — Reusable functions index.
   - **backlog.md** — TODO items found in codebase.

   Run `/s:scan` to analyze your codebase and generate skills.
   ```

3. Show summary of created files. Suggest user run `/s:scan` to analyze their codebase and generate project-specific skills.
